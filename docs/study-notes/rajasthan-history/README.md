## Completion rule for each topic

A topic cannot be marked complete based on a fixed number of questions. For every relevant point:
1. Break it into a single testable fact or skill and write a clear Hindi question with a direct answer.
2. Cover names, dates, places, chronology, definitions, classifications, key examples, causes/effects, comparisons, sources, maps/inscriptions/artefacts, and disputed interpretations as applicable.
3. Attach an authoritative source URL and exact page/section/table/inscription/plate locator to every factual answer.
4. Record conflicting dates/names and uncertainty visibly; do not turn hypotheses into facts.
5. Remove exact and semantic duplicates.
6. Keep drafts as `NEEDS_REVIEW` until independent source/answer review. No AI self-approval.
7. Reconcile the topic's checklist and gap report before the next topic is labelled complete.

## Fixed workflow

**Research sources → knowledge-point checklist → one-liner Q&A draft → duplicate check → independent fact review → coverage audit → ready notes → next topic.**

Only after the notes are reviewed should the app derive practice MCQs and topic tests. Actual previous-year questions remain a separate, answer-key-verified data type.
